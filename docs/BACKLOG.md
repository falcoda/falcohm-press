## Comment on sort une piste d'ici

1. `docs/PARTNER-MATRIX.md` : le module existe-t-il ? Sinon, le créer.
2. `knowledge/<Piste>.md` : ce qu'ils soutiennent déjà, leurs mots, **qui décide**, adresse prouvée.
3. Seulement alors : `targets/`, `crm/companies/`, et le score.
