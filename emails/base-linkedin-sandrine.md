## Ce que ces textes font, et pourquoi

1. **Le commentaire reprend sa propre phrase** (« create the stage and leave it to the talent ») :
   on montre qu'on a lu, et on se place dans son récit sans le détourner.
2. **« On set », jamais « we did the sound »** : le système était un élément de décor.
3. **Les deux marques sont nommées**, chacune avec son rôle : le matériel, les événements.
4. **La note d'invitation finit sur une question fermée** dont la réponse est l'adresse qui nous
   manque. Elle demande un e-mail, pas un appel.
